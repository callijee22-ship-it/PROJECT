# Delta Lake Medallion

**SK네트웍스 Family 엔코아AI캠퍼스 AI 레디 데이터 엔지니어링 캠프 2기**에서 진행한 프로젝트 기록입니다.

## 프로젝트 개요

데이터를 원천 수집 단계부터 정제·가공·활용 단계까지 나누어 관리하는 **Medallion Architecture**를 학습하고 프로젝트에 적용하는 것을 목표로 합니다.

- Bronze: 원천 데이터 수집 및 보관
- Silver: 정제·검증·스키마 적용
- Gold: 분석과 서비스 활용을 위한 데이터 구성
