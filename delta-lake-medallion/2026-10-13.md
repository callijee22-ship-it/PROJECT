# 2026-10-13 — Delta Lake Medallion 프로젝트 시작

## 프로젝트 시작

SK네트웍스 Family 엔코아AI캠퍼스 AI 레디 데이터 엔지니어링 캠프 2기의 다음 프로젝트로 **Delta Lake Medallion** 프로젝트를 시작했다.

## 프로젝트 목표

F1 경기 데이터를 활용해 드라이버 성능과 팀 운영 역량을 분석하고, 데이터 품질을 검증하는 데이터 엔지니어링 파이프라인을 구축한다.

주요 목표는 다음과 같다.

- 오염·결측 데이터 복구 및 품질 검증
- OpenF1 공개 데이터 수집 및 통합
- Bronze → Silver → Gold 데이터 파이프라인 설계
- 드라이버 영입 후보 비교
- 팀별 피트스톱 운영 벤치마킹
- Django 기반 분석 대시보드 구현

## 처음 확인한 구조

프로젝트는 다음과 같은 데이터 계층 구조를 사용한다.

- **Bronze:** 원본 데이터 보존 및 수집 이력 관리
- **Silver:** 데이터 정제·표준화·참조 무결성 검증
- **Gold:** 드라이버·팀 성능 지표와 의사결정용 데이터 마트

## 프로젝트 시작 시 확인한 원칙

- 원본 데이터는 직접 덮어쓰지 않는다.
- 결측값을 무조건 0으로 대체하지 않는다.
- 복구된 값은 복구 방법과 신뢰도를 기록한다.
- 드라이버 추천은 확정적인 예측이 아니라 근거가 있는 비교 지표로 제공한다.
- 피트크루 분석은 개인이 아닌 팀 단위 운영 벤치마킹으로 한정한다.

## 다음 작업

원천 데이터의 구조와 오염 상태를 프로파일링하고, 데이터 정제 및 검증 규칙을 구체화한다.
