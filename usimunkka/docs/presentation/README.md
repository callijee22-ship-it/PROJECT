## Revision History

### Preliminary Draft

**우심운까_발표자료_초안.pptx**

발표자료 제작 초기에 전체적인 디자인 방향과
슬라이드 구성 방식을 검토하기 위해 제작한 초안입니다.

`우심운까_발표자료_초안.png`는
초기 발표자료의 전체 구성을 한눈에 확인하기 위한 Preview 이미지입니다.

---

### 1. Initial Full Version

**우심운까_발표자료_전체.pptx**

프로젝트 전체 내용을 발표 흐름에 맞춰 구성한 1차 전체 발표자료입니다.

서비스 소개, 운동 장소 추천, 공공데이터 활용,
추천 점수와 데이터 처리 구조 등을 하나의 발표 흐름으로 정리했습니다.

---

### 2. Revised Version

**우심운까_발표자료_전체-수정본.pptx**

1차 전체 발표자료를 기준으로
발표자의 요청과 실제 발표 흐름을 반영하여 수정한 버전입니다.

- 슬라이드 순서 조정
- 설명 문장 수정
- 서비스와 데이터의 연결 관계 보완
- 발표자가 설명하기 어려운 기술 내용 재정리
- 데이터 파이프라인 관련 개념 보완

---

### 3. Final Expected Version

**우심운까_발표자료_최종예상.pptx**

수정 과정에서 데이터 파이프라인의 전체 구조를 다시 학습·정리하고,
발표자의 추가 요청을 반영하여 고도화한 최종 예상 버전입니다.

특히 다음 내용을 보완했습니다.

- 데이터 파이프라인 전체 개념 정리
- 수집 → 예외처리·복구 → RAW 적재 흐름
- 정제 및 데이터 품질 검사(DQ)
- PROCESSED 데이터 구조
- 스케줄링 및 자동화
- 로그·모니터링·알림 구조
- 추천 데이터와 실제 서비스 기능의 연결
- 기술 내용을 발표용 문장과 도식으로 재구성
- 발표자 요청에 따른 추가 수정 및 순서 조정
