# Final Frontend Integration

초기 M4 / PAGE1 작업 이후 팀 통합 과정에서
우심운까의 전체 Frontend 구조와 디자인이 크게 변경되었습니다.

초기에는

`대한민국 지도 → 지역 경쟁 → 운동추천`

흐름을 중심으로 PAGE1을 담당했으며,

최종 서비스에서는

`HOME → MOVE → DIARY → FRIENDS → PROFILE`

구조로 재편되었습니다.

따라서 초기 PAGE1 화면이 최종 서비스에 그대로 남아 있지는 않습니다.

---

## 후반 통합 과정에서 참여한 작업

프로젝트 후반부에는 전체 Frontend 통합 과정에서
사용자 화면과 Visual Asset 관련 작업에 참여했습니다.

주요 참여 내용은 다음과 같습니다.

- 캐릭터 커스터마이징용 이미지 제작
- 여성 / 남성 한복 캐릭터 이미지 제작
- Level 5 해금용 운동복 시안 제작
- 겨울 / 여름 의상 이미지 제작
- 포즈별 의상 적용 이미지 제작
- 캐릭터와 의상을 분리하기 위한 의상 전용 PNG 제작
- 걷기 및 움직임 적용 가능성을 확인하기 위한 Motion Test
- 현재 위치 / 직접 지역 선택을 이용한 운동추천 UX 검토
- 발표자료 및 서비스 화면 정리

---

## 초기 작업과 최종 서비스의 차이

제가 담당했던 초기 M4 / PAGE1은
지역 경쟁과 랭킹을 이용해 사용자의 운동 동기를 만드는 화면이었습니다.

이후 팀 통합 과정에서 서비스 방향과 UI 구조가 변경되면서
초기 화면 일부는 최종 Frontend에서 변경되거나 대체되었습니다.

이 저장소에서는 이를 구분하기 위해

- `archive/page1-m4` : 초기 M4 / PAGE1 담당 작업
- `docs/visual-assets` : 직접 제작한 Visual Asset 및 Motion Test
- `final-integration` : 팀 통합 이후 참여 내용

형태로 정리하고 있습니다.

---

## Scope

최종 서비스 전체는 팀원 공동 작업의 결과물입니다.

본 문서는 최종 서비스 전체를 개인 작업으로 주장하기 위한 것이 아니라,
프로젝트 후반부 통합 과정에서 제가 직접 제작하거나 참여한 영역을
별도로 기록하기 위한 문서입니다.
