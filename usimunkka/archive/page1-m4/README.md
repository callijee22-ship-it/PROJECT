## 2026-09-11 · 프로젝트 시작

공모전 프로젝트에서 **PAGE1 / M4 Frontend**를 담당하면서  
첫 화면 구현을 시작했습니다.

당시에는 HTML / CSS / JavaScript 웹 실습을 진행하던 단계였고,  
실제 프로젝트 화면을 직접 구현하는 것은 처음이었습니다.

처음에는 단순한 HTML 화면부터 시작했습니다.

```html

```

이후 PAGE1의 목적과 필요한 기능을 하나씩 정리하면서  
초기 화면을 확장해 나갔습니다.


## Development Flow

초기 PAGE1은 한 번에 완성한 것이 아니라  
다음 과정을 반복하면서 수정했습니다.

```text
요구사항 확인
      ↓
초기 화면 구현
      ↓
실행
      ↓
문제 발견
      ↓
수정
      ↓
기능 추가
      ↓
팀 공유
      ↓
재수정
```

실제 프로젝트에서는 이후 팀 통합 과정에서  
전체 서비스 구조와 UI가 크게 변경되었습니다.

따라서 이 Archive의 코드는  
현재 최종 서비스와 동일한 형태는 아닙니다.

대신 프로젝트 초기에 맡았던 PAGE1이  
어떤 과정을 거쳐 만들어졌는지 확인할 수 있는  
**개발 과정 기록**으로 보관합니다.
