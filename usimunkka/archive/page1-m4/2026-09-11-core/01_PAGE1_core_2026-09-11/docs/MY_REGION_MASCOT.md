# PAGE1 / M4 — 로그인 주소지 기반 MY REGION 마스코트

## 목적
로그인 사용자 프로필의 주소지에서 시·도를 판별하여 `우리 동네는 지금` 영역에 지역 마스코트와 최신 지역 순위를 함께 표시한다.

## 구현 파일
- `dist/mascots.js`: 17개 시·도용 우심운까 오리지널 2D SVG 마스코트와 주소 정규화
- `dist/landing.js`: 로그인 세션 → 주소지 판별 → 최신 랭킹 → UI 렌더링
- `dist/services/rankingApi.js`: 로그인 사용자 프로필 계약 / MOCK 세션

## 처리 흐름
1. `/api/users/me` 또는 MOCK 세션에서 로그인 사용자 프로필 조회
2. `province`, `sido`, `address`, `road_address`, `jibun_address`에서 시·도 정규화
3. 최신 `activity_daily` Snapshot 결과에서 해당 시·도 랭킹 조회
4. MY REGION에 시·도명, 순위, 전일 대비 변화, 시·군·구, 마스코트 표시
5. 주소는 식별되지만 랭킹 데이터가 없으면 마스코트는 표시하고 순위는 `—` 처리

## 마스코트 원칙
현재 마스코트는 지자체 공식 캐릭터를 복제한 것이 아니라 우심운까 UI를 위해 코드로 제작한 오리지널 지역 상징형 SVG다. 실제 지자체 공식 마스코트를 사용할 경우 별도의 사용 권한/가이드 확인이 필요하다.

## 17개 시·도 지원
서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주.


## 지역 랭킹 팝업 연동
- 지도에서 지역을 선택하면 시군구 랭킹 팝업의 지역명 오른쪽에 해당 시·도 마스코트를 표시한다.
- 팝업 마스코트는 기존 `regionMascotSvg()`를 재사용하며 별도 이미지 파일 의존성을 추가하지 않는다.
- 현재 통합 표기인 `전남광주통합특별시`는 팝업에서 광주 지역 마스코트를 사용한다.
