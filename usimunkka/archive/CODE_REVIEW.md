오늘은 초기 Landing Page HTML을 처음부터 다시 읽기 시작했습니다.

### 오늘 이해한 범위

원본 코드:


---

## Line 1

```html
<!doctype html>
```

HTML 문서를 시작하면서

> 이 문서는 HTML5 형식의 문서입니다.

라고 브라우저에 알려주는 선언이다.

HTML 화면에 직접 표시되는 내용은 아니고,  
브라우저가 문서를 어떤 방식으로 해석해야 하는지 알려주는 역할을 한다.

### 내가 이해한 방식

```text
doctype
→ 브라우저에게 "이거 HTML 문서야"라고 먼저 알려주기
```

---

## Line 2

```html
<html lang="ko">
```

HTML 문서 전체가 시작되는 태그다.

```html
<html>
```

부터 실제 HTML 문서가 시작되고,

```html
lang="ko"
```

는 이 페이지의 기본 언어가 한국어라는 뜻이다.

### 내가 이해한 방식

```text
html
→ HTML 문서 전체를 감싸는 시작점

lang="ko"
→ 이 페이지는 한국어 페이지
```

---

## Line 3

```html
<head>
```

화면에 직접 보여줄 본문을 작성하는 부분이 아니라  
웹페이지에 대한 설정과 정보를 넣는 영역이다.

이 안에 문자 인코딩, 화면 크기 설정, 제목, CSS 연결 등의 정보가 들어간다.

### 내가 이해한 방식

```text
head
→ 페이지를 보여주기 전에 필요한 설정을 적는 곳
```

아직 실제 화면 내용은 시작되지 않았다.

---

## Line 4

```html
<meta charset="utf-8">
```

웹페이지에서 사용할 문자 인코딩을 UTF-8로 설정한다.

한글을 포함한 여러 문자가 깨지지 않도록  
브라우저에 문자 처리 방식을 알려준다.

### 내가 이해한 방식

```text
charset
→ 글자를 어떤 방식으로 읽을지 설정

utf-8
→ 한글을 포함한 여러 문자를 사용할 수 있는 문자 인코딩
```

---

## Line 5

```html
<meta name="viewport" content="width=device-width,initial-scale=1">
```

모바일이나 화면 크기가 다른 기기에서  
페이지가 화면 크기에 맞게 표시되도록 설정한다.

### 나눠서 보기

```text
viewport
→ 사용자가 보고 있는 화면 영역

width=device-width
→ 페이지 너비를 현재 기기의 화면 너비에 맞춤

initial-scale=1
→ 처음 페이지를 열었을 때 기본 확대 비율을 1배로 설정
```

### 내가 이해한 방식

```text
PC 화면만 기준으로 보여주는 것이 아니라
현재 사용 중인 기기 화면 크기에 맞춰 보여주기 위한 설정
```

---

# 오늘 이해한 구조

다섯 줄을 한 번에 보면:

```text
HTML5 문서라고 알림
        ↓
HTML 문서 시작
        ↓
페이지 설정 영역 시작
        ↓
문자 인코딩 설정
        ↓
기기 화면 크기 설정
```

즉 아직 지도나 버튼 같은 실제 화면을 만드는 코드가 아니라,  
**웹페이지 자체를 시작하기 위한 기본 설정 부분**을 보고 있었다.

---

## 오늘의 한 줄
