# 2026-10-13 프로젝트 시작

## 시작한 프로젝트

F1 경기 데이터를 기반으로 드라이버 영입 후보와 팀 운영 역량을 분석하는 프로젝트를 시작했다.

## 프로젝트 방향

- OpenF1 공개 데이터를 수집하고 분석한다.
- 오염·결측 데이터를 정제하고 복구 과정을 추적한다.
- 드라이버별 상대 페이스, 일관성, 타이어 성과, 완주 실적을 비교한다.
- 팀별 피트스톱 운영 성과를 분석한다.
- 최종적으로 Django 대시보드에서 드라이버 후보와 팀 운영을 비교한다.

## 데이터 구조

- Bronze: 원본 데이터 보존
- Silver: 데이터 정제·표준화·통합
- Gold: 분석 지표와 추천 결과 생성

## 시작 시 정한 원칙

- 원본 데이터는 덮어쓰지 않는다.
- 결측값을 무조건 0으로 채우지 않는다.
- 복구 방법과 신뢰도를 기록한다.
- 추천 결과는 확정적 예측이 아닌 비교 지표로 제공한다.
- 피트크루 분석은 개인이 아닌 팀 단위 운영 벤치마킹으로 한정한다.

## 다음 작업 방향

원천 데이터 구조와 오염 상태를 확인하고, 데이터 프로파일링 및 정제 규칙을 설계한다.
