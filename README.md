# SK네트웍스 Family 엔코아AI캠퍼스 AI 레디 데이터 엔지니어링 캠프 2기

이 저장소는 **SK네트웍스 Family 엔코아AI캠퍼스 AI 레디 데이터 엔지니어링 캠프 2기**에서 진행한 프로젝트 기록을 관리하는 공간입니다.

## 프로젝트

- `usimunkka/`: 우심운까 프로젝트
- `worklog/`: 날짜별 프로젝트 진행 기록

## 기록 원칙

- 작업한 날짜를 기준으로 기록합니다.
- 프로젝트의 진행 과정, 결정 사항, 문제 해결 과정과 다음 작업을 남깁니다.
- 원본 프로젝트 파일과 작업 기록을 구분해 관리합니다.
